مشروع: نظام إدارة مطعم متكامل (Restaurant Management System)

أريد منك العمل كمطور برمجيات Full Stack Senior Software Engineer ومهندس أنظمة محترف، وتنفيذ نظام إدارة مطاعم متكامل Production Ready باستخدام التقنيات التالية:

Backend: Laravel 12 أو أحدث إصدار مستقر متوافق مع المشروع.
Frontend: React.js مع TypeScript.
Database: MySQL 8.
API: Laravel RESTful API.
UI Framework: Tailwind CSS.
UI Components: مكتبة حديثة ومتناسقة.
Authentication: Laravel Sanctum.
State Management: Zustand أو Redux Toolkit.
Charts: Recharts.
Icons: Lucide React.
أولاً: الهدف من المشروع

إنشاء نظام احترافي لإدارة المطاعم والكافيهات، يغطي جميع العمليات اليومية والإدارية والمالية والتشغيلية، مع لوحة تحكم مركزية وتصميم عصري وسهل الاستخدام.

يجب أن يكون النظام حقيقياً ومتكاملاً، وليس مجرد واجهات تجريبية أو بيانات وهمية.

عاشراً: تعليمات إلزامية أثناء التنفيذ
لا تكتفِ بإنشاء التصميم، بل نفذ الوظائف الحقيقية كاملة.
لا تستخدم بيانات وهمية بدلاً من قاعدة البيانات الحقيقية.
لا تترك أزراراً بدون وظائف.
اربط كل صفحة بالـ API الخاص بها.
لا تضع جميع الأكواد في ملفات ضخمة.
استخدم أحدث الإصدارات المستقرة والمتوافقة.
حافظ على جودة الكود وقابليته للصيانة.
لا تحذف أي وظيفة موجودة عند إضافة وظيفة جديدة.
لا تتوقف عند إنشاء الملفات؛ شغّل المشروع واختبره.
أصلح جميع الأخطاء التي تظهر أثناء التنفيذ.
أنشئ ملف README يحتوي على تعليمات التثبيت والتشغيل.
أنشئ ملف .env.example دون وضع كلمات مرور حقيقية.
لا تدّعِ اكتمال أي وحدة قبل اختبار وظائفها.
استخدم بيانات Seeders للتجربة فقط، مع الفصل بينها وبين بيانات الإنتاج.
إذا كانت هناك تفاصيل غير محددة، اتخذ قراراً هندسياً مناسباً ووثقه بدلاً من تعطيل التنفيذ.
